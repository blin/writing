title: "How to Reference a Book"
date: 2026-08-29T19:00:00+01:00

---

I want a book reference to be unambiguous and also to serve as an on-ramp
to learn more about the book.

If I mention a book by "title and author" there is (usually) little ambiguity --
"Mutual Aid by Petr Kropotkin" is easily distinguished from
"Mutual Aid by Dean Spade"[^1]. As an on-ramp to learning more
"title and author" alone can lead to inconsistent results.
Will someone use a search engine or a book store website? Which if any?

[^1]: I usually do not include the
  [subtitle](https://en.wikipedia.org/wiki/Subtitle_(titling)).

I used to include a link to an
[Amazon](https://en.wikipedia.org/wiki/Amazon_(company))
page for the book, but at some point I got an aversion to promoting Amazon.

I then started including an
[ISBN](https://en.wikipedia.org/wiki/ISBN)
for some edition of the book alongside the author and title.
Searching for an ISBN can be a bit more efficient then by "title and author",
especially when using unsophisticated search engines
(on library websites for example), and an ISBN is more durable than any
specific book store page.
There are a couple of problems with ISBNs though: the ISBN database is not
in the public domain (nor freely licensed)
and ISBNs were not assigned to books published before
the ISBN standard was invented.

Later still I have discovered [WorldCat](https://en.wikipedia.org/wiki/WorldCat),
an aggregator of library catalogues, who's
[catalogue identifiers](https://en.wikipedia.org/wiki/OCLC#Identifiers_and_linked_data)
are in the public domain. Thus a link to a book page on WorldCat
(the link includes an OCLC number)
gives a durable reference, includes a description (usually), and shows nearest
libraries that hold a copy of the book!

I now reference a book by title, author(s) name and a link to WorldCat.
The two "Mutual Aid" books mentioned earlier I would reference as
[Mutual Aid by Petr Kropotkin](https://search.worldcat.org/title/1259589204)
and
[Mutual Aid by Dean Spade](https://search.worldcat.org/title/1198450425).
